# InfluPay

A full-stack marketplace connecting brands with influencers — built to simplify discovery, matching, and booking for influencer marketing collaborations.

## About

InfluPay is a marketplace platform that bridges the gap between brands and influencers, making it easy to discover the right match, negotiate collaborations, and manage bookings end-to-end. Built as part of my work in full-stack development, it focuses on a smooth, intuitive experience for both sides of the marketplace.

## Features

- Influencer discovery and profile browsing
- Brand-influencer matching based on niche, audience, and goals
- Booking and collaboration request workflow
- Payment handling for completed collaborations
- Dashboard for brands and influencers to manage active and past deals

## Tech Stack

React.js • JavaScript • Node.js • REST APIs

## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm 9+ (or compatible)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/msnkhp/influpay.git
cd influpay
```

2. Install dependencies:

```bash
npm install
```

3. Start the local development server:

```bash
npm run dev
```

4. Open the URL shown in the terminal (typically `http://localhost:5173` or `http://localhost:3000`).
